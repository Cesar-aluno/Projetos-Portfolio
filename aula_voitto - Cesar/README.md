# Voitto Cakes

Site estático de receitas de bolos, desenvolvido com HTML e CSS.

## Páginas

- Página inicial com links para as receitas.
- Receita de bolo de chocolate.
- Receita de bolo de laranja.
- Receita de bolo de limão.

## Tecnologias

- HTML5 semântico
- CSS3
- Layout responsivo com Flexbox, Grid e media queries

## Como visualizar

Abra o arquivo `index.html` no navegador. Para que as fotografias apareçam, mantenha a pasta `images/` do projeto original com os nomes de arquivos referenciados no HTML.

## Observação

Este projeto foi criado para estudo e portfólio.
